# Bảng thuật ngữ

Dùng thống nhất trong mọi tài liệu và trong tin gửi khách. Cột "Tránh" là cách viết không dùng.

| Dùng | Tránh | Ghi chú |
|---|---|---|
| hệ hòa lưới (On-Grid) | ongrid, hệ bám tải | Hệ không có pin lưu trữ |
| hệ Hybrid | Hy-Brid, hệ lai | Hệ có pin lưu trữ |
| pin lưu trữ | ắc quy, bình | |
| tấm pin | panel, tấm năng lượng | |
| biến tần (inverter) | kích điện | |
| kWp | kW (khi nói công suất hệ) | Công suất đỉnh của hệ |
| kWh | số điện (trong tài liệu) | Khi nói với khách có thể nói "số điện" |
| hóa đơn tiền điện | bill | |
| 1 pha, 3 pha | 1P, 3P | |
| mái tôn, mái ngói, mái bằng | mái fibro, sân thượng | Mái bằng là mái bê tông |
| khảo sát | đo đạc | Nhân viên tới xem mái trước khi báo giá cuối |
| báo giá | chào giá | |
